# Types as Contracts — From C# Records to Generated TypeScript

The through-line of this file: in this repo, **types are not documentation, they are enforcement**. A C# command record becomes JSON schema becomes generated TypeScript. Break the chain anywhere and the compiler — someone's compiler — tells you.

## 1. The contract chain

```
C# command/DTO record          OpenAPI document              TypeScript client
CreateTodoItemCommand   ──►   /openapi/v1.json        ──►   web-api-client.ts
(Application layer)           (served by Web,               (generated by NSwag on
                               shaped by transformers)       npm prestart/prebuild)
```

- Source: [CreateTodoItemCommand](../../src/Application/TodoItems/Commands/CreateTodoItem/CreateTodoItem.cs#L6-L11).
- OpenAPI generation: `AddOpenApi` with transformers ([Web/DependencyInjection.cs L27-L34](../../src/Web/DependencyInjection.cs#L27-L34)); operation ids come from handler method names ([EndpointRouteBuilderExtensions.cs L5-L11](../../src/Web/Infrastructure/EndpointRouteBuilderExtensions.cs#L5-L11)).
- Client generation: [nswag.json](../../src/Web/ClientApp-React/nswag.json#L4-L11) reads `../wwwroot/openapi/v1.json` and emits `src/web-api-client.ts` ([L72](../../src/Web/ClientApp-React/nswag.json#L72)); wired as `prestart`/`prebuild` ([package.json L27-L35](../../src/Web/ClientApp-React/package.json#L27-L35)). The generated file is not committed.
- Consumption: `new TodoItemsClient().createTodoItem({ title, listId })` ([Todo.jsx L218](../../src/Web/ClientApp-React/src/components/Todo.jsx#L218)).

Consequences you must be able to narrate:
- Rename the C# property `Title` → `Name` and the *frontend build breaks* (after regen) instead of silently sending ignored JSON. That's the whole point.
- Rename the endpoint **method** `GetTodoLists` and every client call site changes name. Method names are public API here — unusual, and a great "what's your blast radius?" example.
- The transformers keep the *error* contract honest too: every operation documents 400 because [ValidationBehaviour](../../src/Application/Common/Behaviours/ValidationBehaviour.cs) can 400 anything ([ApiExceptionOperationTransformer L17-L27](../../src/Web/Infrastructure/ApiExceptionOperationTransformer.cs#L15-L29)); 401/403 only where auth metadata exists.

Transferable: this is one instance of **contract-first client generation**. Equivalents you'll meet elsewhere: OpenAPI+orval/openapi-typescript, tRPC (types shared without codegen), GraphQL codegen, gRPC/protobuf. In an interview, name the family, not just the tool.

## 2. Nullability across the boundary

C# `string?` becomes an optional TS property (`markOptionalProperties: true`, [nswag.json L47](../../src/Web/ClientApp-React/nswag.json#L47)). Look at [TodoItemDto](../../src/Application/TodoLists/Queries/GetTodos/TodoItemDto.cs): `Title` is `string?` even though the DB requires it ([TodoItemConfiguration L11-L13](../../src/Infrastructure/Data/Configurations/TodoItemConfiguration.cs#L11-L13)). So the *frontend* type says "title may be missing" though it never is. Contract looser than reality = every consumer pays a null-check tax or (as [Todo.jsx](../../src/Web/ClientApp-React/src/components/Todo.jsx#L281-L283) does) just ignores the possibility. Tightening DTO nullability to match truth is a quality ticket in [06-contribution-practice](../06-contribution-practice/01-good-first-tickets.md).

## 3. Enums across the boundary

`PriorityLevel` crosses as a **number**: the DTO flattens it via `(int)s.Priority` in the AutoMapper profile ([TodoItemDto.cs L19-L26](../../src/Application/TodoLists/Queries/GetTodos/TodoItemDto.cs#L19-L26)), and the UI receives the human-readable names separately as lookup data ([GetTodos.cs L27-L30](../../src/Application/TodoLists/Queries/GetTodos/GetTodos.cs#L27-L30)). Tradeoff: ints are stable and compact but opaque; strings are readable but renaming an enum member becomes a breaking wire change. Whichever you pick, *say it's a choice*.

## 4. Generics and constraints as design tools

- The behaviours are **open generics**: `ValidationBehaviour<TRequest, TResponse>` registered once via `AddOpenBehavior(typeof(ValidationBehaviour<,>))` ([DependencyInjection.cs L21](../../src/Application/DependencyInjection.cs#L21)) and closed by DI per request type. One class, every request.
- Constraint as contract: `where TRequest : notnull` ([ValidationBehaviour.cs L5-L6](../../src/Application/Common/Behaviours/ValidationBehaviour.cs#L5-L6)).
- `IRequest<int>` vs `IRequest` — return type is part of the message contract; compare [CreateTodoItemCommand : IRequest<int>](../../src/Application/TodoItems/Commands/CreateTodoItem/CreateTodoItem.cs#L6) with [DeleteTodoItemCommand : IRequest](../../src/Application/TodoItems/Commands/DeleteTodoItem/DeleteTodoItem.cs#L5). The endpoint's HTTP status mirrors it: 201-with-body vs 204.
- `static abstract`/`static virtual` members ([IEndpointGroup L16-L18](../../src/Web/Infrastructure/IEndpointGroup.cs#L16-L18)) — interface members on the *type*, not instances; the registration code calls them via reflection ([WebApplicationExtensions L21-L24](../../src/Web/Infrastructure/WebApplicationExtensions.cs#L21-L24)).

## 5. Where the type system is weakest here — and how to read that in any repo

- **JSX, not TSX:** the React app's own components are `.jsx` — untyped at the component seam ([Todo.jsx](../../src/Web/ClientApp-React/src/components/Todo.jsx)). Only the *generated client* is TypeScript. So type safety exists at the network boundary but evaporates inside the UI. A `tsconfig.json` exists and `typescript` is a dev dependency; migrating components to TSX is a realistic mid-level ticket.
- **`as` casts in the Angular client:** `this.listOptionsEditor as UpdateTodoListCommand` ([todo.component.ts L119](../../src/Web/ClientApp/src/app/todo/todo.component.ts#L115-L119)) with `listOptionsEditor: any` ([L29](../../src/Web/ClientApp/src/app/todo/todo.component.ts#L29)) — casting `any` into a generated type asserts, not verifies. This is the TS equivalent of `null!`: a place the developer overruled the checker.
- **Stringly-typed reflection:** `type.GetProperty(nameof(IEndpointGroup.RoutePrefix))` ([WebApplicationExtensions L21-L22](../../src/Web/Infrastructure/WebApplicationExtensions.cs#L21-L22)) — `nameof` keeps it rename-safe; note how the repo consistently prefers `nameof` over raw strings (e.g. route in [TodoItems.cs L27](../../src/Web/Endpoints/TodoItems.cs#L27)).

Reading skill: in any codebase, grep for `any`, `as `, `null!`, `!` (TS non-null), `dynamic`, `object`. The density and location of type-system escape hatches tells you where the honest contracts end.

## Drills

1. **Break the chain on purpose (thought experiment):** you change `UpdateTodoItemCommand.Done` from `bool` to `bool?`. List everything that changes downstream, in order (OpenAPI schema → regenerated client type → `updateCheckbox` call site behavior → validator?). Strong answers notice nothing *forces* the React `.jsx` call sites to update — the untyped seam swallows it.
2. **Contract archaeology:** [Web.http](../../src/Web/Web.http) encodes an older contract (`GET /api/TodoLists/1`, paginated `/api/TodoItems`, `/Identity/Account/Login`). Diff it against the real endpoint groups and write the list of drifts. (This becomes a real ticket in [06-contribution-practice/01](../06-contribution-practice/01-good-first-tickets.md).)
3. **Design call:** should `TodoItemDto.Priority` be the enum name string instead of an int? Write three sentences each way, then decide. There is no right answer; there is a defended answer.
