# 04 — Code Reading Gym

Reading code is a trained skill with drills, like sight-reading music. This module makes you *work*: annotate real excerpts, fill trace tables, judge fake code against real patterns, and review realistic PRs — always with self-grading rubrics.

| File | Exercise type | Count |
|---|---|---|
| [01-annotation-drills.md](01-annotation-drills.md) | Annotate real excerpts: inputs, outputs, dependencies, invariants, side effects, failure modes | 8 |
| [02-trace-tables.md](02-trace-tables.md) | Step-by-step traces with value shapes and risk columns | 5 |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | Bad-vs-better pairs tied to this repo's patterns | 9 |
| [04-review-katas.md](04-review-katas.md) | Fake PRs to review, findings graded blocking/important/optional | 8 |

House rules: write your answer down **before** reading the rubric (the act of committing is the exercise); do at most two drills per sitting; say hard ones out loud — every drill here is a dress rehearsal for the "read this code and tell me about it" interview round.
